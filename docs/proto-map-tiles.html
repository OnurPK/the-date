Map tiles — a locked place is a sketch; unlocking builds it

The real map (3072×2048). Netherfield's grounds are cut out on an organic mask: locked = an empty plot (meadow, a pegged-out ground plan, no building — what gets built is the surprise); unlock = a construction time-lapse ends on the painted tile. Unlock plays the Seedance time-lapse (pegs → foundations → walls → timber roof → scaffolding → the finished house), keyed to alpha and masked to the tile shape; it ends on the painted tile. Untick the box to see the earlier canvas fake instead. Toggle the sketch variants; click the lock pin to unlock; Reset to lock again.
