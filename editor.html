Syntax

      

        

          

            
Dialogue

            Speaker: line text — Boy, Girl, Dog, Eros, Valium, Romeo, Professore, Narrative
          

          

            
Tags (suffix any line)

            (+5) adds 5 to the 0-100 Know score.

            (cutscene01.png) swaps the cinematic background.

            (none) clears the active cutscene.
          

          

            
Flow directives (own line)

            (Explore:30) — 30 second explore. 

            (Choice:N) + next N lines are the options.

            (Scene:narrativescene01.png) — couch / 2-person bubble mode.

            (Scene:none) — leave scene mode.
          

          

            
Objects & actions

            (Object:id image=file.png) — image focus object.

            (Object:id character=dog) — character encounter.

            (Action) inside an object — first line = prompt, rest = scene.
